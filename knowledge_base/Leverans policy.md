# Leveranspolicy


# Leveranstid  

Standardleveranser beräknas ta 2–5 arbetsdagar från att beställningen har skickats.  Leveranstiden är en uppskattning och kan variera beroende på transportör och destination.  

# Fraktkostnad  

Standardfrakt kostar 49 kr per beställning.  Fri standardfrakt erbjuds vid köp för minst 800 kr.  

# Spårning  

När en beställning skickas får kunden ett spårningsnummer via e-post.  Kunden kan använda spårningsnumret hos den aktuella transportören för att följa leveransen.  

# Försenad leverans  

Om en leverans inte har kommit fram inom den beräknade leveranstiden bör kunden kontakta kundservice.  

# Begränsningar 

Assistenten har inte tillgång till riktiga orderuppgifter eller transportörernas spårningssystem. Den får därför inte påstå att den kan kontrollera en specifik beställning.
